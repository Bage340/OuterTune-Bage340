# OuterTune 0.11.1 v92 — Preview

Подписанный тестовый APK для проверки на телефоне. Это обновление **существующего пререлиза** `0.11.1-v92`, не Stable-релиз.

## Что изменилось

- Локальная библиотека и сканер: сохраняются данные при неполном обходе SAF/ошибках чтения; добавление всех песен локального плейлиста в библиотеку выполняется без дублирования записей.
- Загрузки: предварительная проверка всей пачки пропускает уже скачанное и активную очередь, исправляет устаревшие отметки, повторяет неудачные загрузки со свежим URL; число параллельных загрузок выбирается от 1 до 3 (по умолчанию 1). Файлы Stable и Preview различаются даже при ошибочном выборе общей папки.
- Тексты песен: YouTube остаётся первым источником; другие провайдеры используются при отсутствии результата, с проверкой совпадения трека и предпочтением синхронизированного текста, когда он подходит.
- Перенос: экспорт и подтверждаемый импорт библиотеки/плейлистов в JSON, CSV и M3U8; проверка входных данных и атомарное сохранение защищают от частичного импорта.
- Импорт удалённого плейлиста создаёт безопасную локальную копию: файл переноса не может привязать плейлист к вашему YouTube-аккаунту или выполнить действия с ним. Уже существующий онлайн-плейлист при повторном импорте не меняется.
- Интерфейс и переводы: отдельные название и значок Preview, обновлены строки 51 локали. Предыдущие исправления воспроизведения, сканера и папок плейлистов сохранены.

## Установка и данные

APK имеет пакет `com.dd3boh.outertune.preview`, версию `0.11.1`, `versionCode 92` и отдельный ключ подписи. Он устанавливается рядом с обычным `com.dd3boh.outertune`, а не поверх него. Данные приложений разделены; для переноса воспользуйтесь экспортом и импортом. Перед проверкой на важных данных сделайте резервную копию. При замене уже установленного Preview v92 Android может потребовать удалить старый Preview — это удалит **его** локальные данные; сначала сделайте экспорт или резервную копию. Не удаляйте Stable ради установки Preview.

Если старый Preview уже сохранял треки в выбранную вами папку, его файлы без префикса `otpreview-` остаются на диске, но новая версия не принимает их за собственные загрузки: в общей папке невозможно надёжно отличить их от файлов Stable. Сохраните копию папки до обновления; такие треки можно открыть как локальные файлы либо скачать заново в Preview. Не удаляйте старые файлы до проверки.

## Проверено и не проверено

Локально прошли по 198 unit-тестов для Stable и Preview, тесты библиотек KuGou и SimpMusic, проверка переводов (51 локаль, 574 ключа, 0 дефектов), сборки Core/Full и проверка подписанного Preview APK. Инструментальные тесты только скомпилированы; на телефоне они не запускались. Поведение на устройстве, сервис YouTube, параллельные загрузки и реакция Play Protect не могут быть гарантированы без проверки пользователем. Полный план: [PHONE_TEST_PLAN.md](PHONE_TEST_PLAN.md).
