# OuterTune 0.11.1 v92 — Stable

Stable опубликован по явной команде владельца после согласованной минимальной
приёмки Preview. Сохранены версия v92, исторический тег и прежние ключи каналов.

Последний обзор всей версии и исправлений:
[ревью 2026-10-08](V92_MEGA_REVIEW_2026-10-08.md). Исправлены сохранность альбомов
при повторном сканировании, полнота ответов библиотеки, копирование плейлистов
после подтверждения, чтение частичного кеша и приоритет готовых файлов,
единый путь отмены загрузок и состояние ручного поиска текстов. На актуальном APK
пройдены обновление без потери данных, полный экспорт существующего плейлиста и
синхронизация его73 песен с точным порядком. В согласованном минимальном объёме
блокеров не осталось; непроверенные сценарии перечислены в отчёте. Предыдущие
результаты с телефона не переносятся автоматически на новую сборку.

## Изменения для пользователя

- Сканер сохраняет песни, избранное, даты и связи с плейлистами при недоступных папках, неполном обходе и ошибках чтения. Улучшено воспроизведение локальных файлов и `content://` URI.
- Резервная копия сохраняет согласованные данные SQLite; повреждённые и посторонние элементы архива отклоняются до замены рабочей базы. Восстановление после прерывания сохраняет возможность отката.
- Загрузки проверяют полноту и читаемость файла. Перенос из кеша сначала сохраняет новую копию. Отмена активной очереди сохраняет готовые файлы, а удаление скачанного аудио сохраняет песни в плейлисте. Параллельность — 1–3, по умолчанию 1.
- Тексты используют настоящее время строк и проверку соответствия записи. Исправлены приоритет синхронизированного текста, поиск KuGou и повторный поиск после ошибок провайдера.
- Перенос JSON/CSV/M3U8 проверяет размер и структуру, сохраняет порядок исполнителей и различие пустого/отсутствующего альбома, объединяет ссылки на один локальный файл. Отменённый импорт откатывается целиком.
- Сохранены папки плейлистов, добавление плейлиста в библиотеку, настройка экрана, очередь и переводы 51 локали.

## Установка и сохранение данных

Полное чтение плейлиста теперь обрабатывает отдельное продолжение с рекомендациями
плейлистов: оно не мешает экспорту и синхронизации и не добавляет рекомендации в
список песен. Неизвестные разделы, неоднозначные ответы и циклы продолжений
отклоняются с сохранением прежних данных. Android 10 отложен владельцем для
текущего финального ревью; это не успешная проверка API 29.

Stable сохраняет пакет `com.dd3boh.outertune` и прежний ключ подписи. Сохраните резервную копию/экспорт и сначала попробуйте обычное обновление Stable. Preview использует `com.dd3boh.outertune.preview` с отдельными данными; установка Stable не переносит их автоматически. Если Android отклонит установку, сохраните текст ошибки и не удаляйте единственную копию данных. Ревью исходников и минимальная приёмка на Poco пройдены в Preview; новые Stable APK собраны и проверены без замены Stable на телефоне. См. [правила релизов](RELEASE_POLICY.md), [заметки о сборке](../CUSTOM_BUILD.md) и [результаты ревью](V92_MEGA_REVIEW_2026-10-08.md).

Выбранные внешние папки могут быть общими. Старые файлы Preview без префикса `otpreview-` остаются на диске, но не считаются автоматически его собственными загрузками. Сохраните копию папки; старые треки можно открыть как локальные файлы. Не удаляйте их до проверки.

## Техническая проверка и источник

Опубликованы подписанные **Stable Core Release** и **Stable Full Release** с R8 и сокращением ресурсов: universal и четыре отдельные архитектуры для каждого варианта. [CI 38159046409](https://github.com/Bage340/OuterTune-Bage340/actions/runs/38159046409) успешно выполнил unit-тесты Stable Core/Full, lint Core и сборки обоих вариантов. CI не прикладывает test XML, поэтому число выполненных тестов не выдумывается. [Минимальная приёмка на телефоне](V92_MEGA_REVIEW_2026-10-08.md) выполнена в Preview из тех же исходников; установка нового Stable на телефон не выполнялась. Живые тесты внешних сервисов требуют opt-in; пропуски не считаются успешными проверками.
