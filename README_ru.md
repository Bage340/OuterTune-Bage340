Независимый публичный форк [OuterTune](https://github.com/OuterTune/OuterTune) — Android-клиента YouTube Music и локального музыкального проигрывателя. В этом форке сохранены работа с YouTube Music и воспроизведение файлов на устройстве, а также добавлены выбранные исправления и совместимые бэкпорты для воспроизведения, загрузок и локальной медиатеки. Интерфейс приложения переведён на несколько языков.

> [!IMPORTANT]
> Этот репозиторий независим и **не является** официальным проектом OuterTune или официальным каналом его сопровождающих. Оригинальный проект, его историю и собственные релизы см. в [OuterTune/OuterTune](https://github.com/OuterTune/OuterTune).

## Возможности форка

- Поиск и воспроизведение из YouTube Music, плейлисты, синхронизация аккаунта, тексты песен и необязательные офлайн-загрузки
- Обновление плейлиста сохраняет непустую локальную копию при неполном или неподтверждённом пустом ответе; действительно очищенный удалённый плейлист может временно сохранять прежнее локальное содержимое.
- Полная синхронизация и экспорт отклоняют необработанное продолжение списка, если полнота ответа не подтверждена; доступные песни остаются видны при просмотре.
- Воспроизведение локальных аудиофайлов вместе с контентом YouTube Music
- Сканирование, просмотр и фильтрация локальной медиатеки, добавление песен из плейлиста в библиотеку, перенос библиотеки и плейлистов в JSON/CSV и перенос плейлистов в M3U8
- Фильтрация очереди загрузок и повторные попытки; по умолчанию сохраняется консервативный лимит параллельных загрузок
- Ограниченное время ожидания необязательного PoToken YouTube и независимая отмена параллельных запросов
- Каналы Stable и Preview с разными идентификаторами пакетов и отдельными данными приложения
- Интерфейс Material 3 для Android, несколько очередей воспроизведения, Android Auto, аудиоэффекты и многоязычные ресурсы
- Точечные улучшения надёжности и выбранные бэкпорты; их состав отражён в истории и pull request'ах этого репозитория

Доступность функций зависит от устройства, аккаунта, сети, региона, провайдера и варианта сборки. YouTube Music недоступен в части регионов; при необходимости используйте прокси или VPN только там, где это законно и уместно.

## Установка или сборка

[Ревью v92 от 2026-10-08](docs/V92_MEGA_REVIEW_2026-10-08.md) описывает
последние исправления и оставшиеся проверки приёмки. Неизвестный формат старого
частичного кеша отклоняется для сохранности аудио; успешная синхронизация аккаунта
и приёмка на телефоне проверяются отдельно от исходного кода и сборки.

Текущий релиз — **OuterTune 0.11.1 v92 — Stable** (Android `versionCode` 92), тег `0.11.1-v92`. Скачайте [Core universal](https://github.com/Bage340/OuterTune-Bage340/releases/download/0.11.1-v92/OuterTune-Bage340-0.11.1-v92-stable-core.apk) для обычного использования или [Full universal](https://github.com/Bage340/OuterTune-Bage340/releases/download/0.11.1-v92/OuterTune-Bage340-0.11.1-v92-stable-full.apk) с дополнительным декодером FFmpeg. APK для отдельных архитектур и принятая сборка Preview остаются на [странице релиза](https://github.com/Bage340/OuterTune-Bage340/releases/tag/0.11.1-v92).

Stable сохраняет пакет `com.dd3boh.outertune` и прежний ключ подписи. Сохраните резервную копию/экспорт и сначала попробуйте обычное обновление Stable. Preview использует `com.dd3boh.outertune.preview` с отдельными данными; установка Stable не переносит их автоматически. Если Android отклонит установку, сохраните текст ошибки и не удаляйте единственную копию данных. Ревью исходников и минимальная приёмка на Poco пройдены в Preview; новые Stable APK собраны и проверены без замены Stable на телефоне. См. [правила релизов](docs/RELEASE_POLICY.md), [заметки о сборке](CUSTOM_BUILD.md) и [результаты ревью](docs/V92_MEGA_REVIEW_2026-10-08.md).

Опубликованные APK обоих каналов собраны из `514af1f37d12824188bf0dcbeba0f3724d9321b2`; источник и хеши указаны в `SOURCE_COMMIT.txt` и `SHA256SUMS.txt`. Исторический тег сохранён; его автоматический архив исходников старше этих APK. Для сборки точного исходника выберите commit ниже.

Для сборки из исходного кода клонируйте этот репозиторий вместе с подмодулями и используйте Android Studio или Gradle Wrapper:

```bash
git clone --recurse-submodules https://github.com/Bage340/OuterTune-Bage340.git
cd OuterTune-Bage340
git checkout 514af1f37d12824188bf0dcbeba0f3724d9321b2
git submodule update --init --recursive

# Отладочный APK Core
./gradlew assemblePreviewCoreDebug

# Отладочный APK Full с дополнительным пакетом декодеров FFmpeg
./gradlew assemblePreviewFullDebug
```

В Windows вместо `./gradlew` используйте `./gradlew.bat` или `gradlew.bat`. Предварительные требования, отличия вариантов сборки и правила участия описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
